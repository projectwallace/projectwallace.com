## Features on this page

- See which [web-features](https://github.com/web-platform-dx/web-features) are present in the provided CSS, what their Baseline status is, the browser support, how often it's used and the Baseline date(s).
- Click on a table to go to the actual CSS of that feature to see how exactly it's used.
- Sort all features by name, usage count, Baseline status, Baseline date(s) and browser support.
- Filter features by Baseline level (widely available, newly available, limited availability).
- High-level charts and tables that outline the overall state of the Baseline feature usage in the CSS.

## What this unlocks

- Spot that one CSS feature with very limited support that a rogue dev on your team deployed before the linter could catch it.
- Charts and tables of your CSS. What's not to like? Plenty for CSS archaeologists to dig through.

## Frequently asked questions

### Why is everything cut off at 2018?

This overview only shows features becoming Baseline in 2018 or later since that's when we've started keeping track of Baseline. There is more granular information available from before that, but it's very confusing, especially with the release date of Microsoft's Edge browser in 2017. That's why we've picked 2018 as a starting point.
